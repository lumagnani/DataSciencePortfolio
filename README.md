## Projects
 
### 01. Sales Data Exploratory Analysis
An exploratory analysis of historical sales data aimed at understanding sales behavior, profitability patterns, and regional performance. The project focuses on data quality checks, visual analysis, and business-oriented insights.
 
**Key skills:** Python, Pandas, Data Cleaning, EDA, Data Visualization
 
---
 
### 02. Hospital Readmission Analysis (Python + Power BI)
A data analysis project focused on identifying factors associated with hospital readmission within 30 days. Combines exploratory data analysis in Python with an interactive Power BI dashboard to uncover patterns related to patient health conditions and healthcare outcomes.
 
**Key skills:** Python, Pandas, EDA, Power BI, Data Storytelling, Business Metrics
 
---
 
### 03. Heart Disease Prediction (Python + Power BI)
A supervised machine learning project that predicts whether a patient is at risk of heart disease based on clinical features. The pipeline covers data cleaning, feature engineering, and model evaluation using a Random Forest Classifier. An interactive Power BI dashboard complements the analysis with visual insights into the most relevant risk factors.
 
**Key skills:** Python, Scikit-learn, Machine Learning, Random Forest, Power BI, Data Visualization
 
---
 
### 04. Customer Segmentation Using Clustering 🚧 In Progress
A customer segmentation project using unsupervised learning techniques to identify distinct customer groups. The results highlight behavioral patterns and potential marketing strategies.
 
**Key skills:** Python, Clustering, Unsupervised Learning
 
---
 
### 05. End-to-End Data Science Project 🚧 In Progress
A complete data science workflow that integrates data extraction, analysis, modeling, and visualization. This project simulates a real-world scenario from raw data to actionable insights.
 
**Key skills:** SQL, Python, Machine Learning, Data Visualization
