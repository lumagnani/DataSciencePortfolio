# Hospital Readmission Analysis

A data analysis project focused on identifying factors associated with hospital readmission within 30 days. This project combines **Python for exploratory data analysis (EDA)** and **Power BI for dashboard development** to uncover patterns related to patient health conditions and healthcare outcomes.

---

## Project Overview

Hospital readmissions are a major challenge in healthcare systems, increasing operational costs and affecting patient outcomes.

This project analyzes patient hospitalization data to investigate which factors may influence the probability of readmission within 30 days after discharge.

The analysis explores demographic, clinical, and operational variables to better understand patient risk patterns.

---

## Objectives

The main objectives of this project were:

* Analyze hospital readmission patterns
* Identify potential risk factors associated with readmission
* Compare readmission rates across patient conditions
* Build an interactive dashboard for healthcare insights
* Practice data cleaning, exploratory analysis, and business intelligence

## Dataset

Dataset used:

**Hospital Readmission Prediction (Synthetic Dataset)**

The dataset contains approximately **30,000 patient records** with healthcare-related variables such as:

* Age
* Gender
* BMI
* Cholesterol
* Blood Pressure
* Diabetes
* Hypertension
* Medication Count
* Length of Stay
* Discharge Destination
* 30-Day Readmission

## Questions Explored

This project investigates questions such as:

---

## Key Insights

Some important findings from the analysis include:

* The overall **readmission rate was approximately 12%**
* Patients discharged to **rehabilitation facilities** showed a slightly higher readmission tendency
* Diabetes and hypertension showed **small differences in readmission rates**
* Demographic factors such as gender presented **limited variation**
